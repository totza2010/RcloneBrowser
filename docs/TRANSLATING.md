# การแปล RcloneBrowser

โปรแกรมเขียนเป็นภาษาอังกฤษ ระบบแปลพร้อมแล้วทั้งหน้าต่างและหน้าเว็บ (2026-10-19) แต่**ยังไม่มีภาษาอื่น**
ภาษาที่แปลไม่ครบก็ใช้ได้: คำที่ยังไม่แปลแสดงเป็นภาษาอังกฤษ จึงแปลทีละส่วนได้

ตัวเลขและวันที่ไม่เปลี่ยนตามภาษา — หน้าต่างล็อก locale เป็น UK English ไว้ เพราะโปรแกรมอ่านค่าที่มันเขียนเองกลับมา
(issue #96 ของโครงการเดิม) การแปลเปลี่ยนแค่ถ้อยคำ

## หน้าต่าง (Qt Linguist)

ไฟล์แปลอยู่ที่ `translations/rclonebrowser_<ภาษา>.ts` เช่น `rclonebrowser_th.ts` · CMake หาเองทุกไฟล์ในโฟลเดอร์นั้น
(ต้องมี Qt LinguistTools ซึ่งมากับ Qt) และใส่ `.qm` ที่ได้ไว้ในตัวโปรแกรมที่ `:/i18n/`

1. สร้างไฟล์ของภาษาใหม่ (ครั้งแรก):
   ```
   lupdate src -ts translations/rclonebrowser_th.ts
   ```
   หรือเมื่อมีไฟล์ `.ts` แล้ว: `cmake --build build --target update_translations` ดึงคำใหม่จากโค้ดและไฟล์ `.ui`
2. แปลด้วย Qt Linguist (`linguist translations/rclonebrowser_th.ts`) หรือโปรแกรมแปลที่อ่าน `.ts` ได้
3. `cmake build` แล้ว build ตามปกติ → Preferences → แท็บ **Language** มีภาษานั้นให้เลือก · ใช้ตั้งแต่เปิดโปรแกรมครั้งถัดไป
   ค่าเริ่มต้น: ภาษาของเครื่อง ถ้ามีคำแปล

**ตอนนี้แปลได้แค่ไหน**: `lupdate` เจอ **610 ข้อความ** (2026-10-19) — ส่วนใหญ่มาจากไฟล์ `.ui` ซึ่ง Qt แปลให้เองอยู่แล้ว
ข้อความที่เขียนในโค้ด (`"..."`, `QStringLiteral(...)`) **ยังไม่ผ่าน `tr()`** จึงยังแปลไม่ได้ — ต้องห่อด้วย `tr()` ทีละไฟล์
(ข้อความที่ส่งออกทาง API และ log ไม่ต้องแปล: เป็นของโปรแกรมอื่นอ่าน)

## หน้าเว็บ

ไฟล์แปลคือ `src/webui/i18n/<ภาษา>.json` — ภาษาอังกฤษที่หน้าเว็บพูด → สิ่งที่จะพูดแทน:

```json
{
  "Run": "รัน",
  "Sign out": "ออกจากระบบ"
}
```

- ถูกใส่ไว้ในตัวโปรแกรม (`:/webui/i18n/`) ทุกไฟล์ในโฟลเดอร์ · `en.json` ว่างไว้เป็นแบบ
- หน้าเว็บถาม `GET /api/v1/languages` (ไม่ต้อง sign in) แล้วโหลด `/i18n/<ภาษา>.json` · เลือกจากช่องภาษาที่หัวหน้า
  (ขึ้นเมื่อมีมากกว่าหนึ่งภาษา) · จำใน browser นั้น · ค่าเริ่มต้นตามภาษาของ browser
- ในโค้ด: `t("Run")` แทน `"Run"` — **ยังไม่ได้ห่อข้อความในหน้าเว็บ** ต้องทำทีละส่วน เหมือนหน้าต่าง

## ลำดับที่แนะนำเมื่อจะแปลจริง

1. ห่อข้อความในหน้าเว็บด้วย `t()` และในโค้ดหน้าต่างด้วย `tr()` — งานที่ไม่ต้องรู้ภาษา ทำได้ทีละไฟล์
2. สร้าง `rclonebrowser_th.ts` และ `th.json` แล้วแปล
3. ข้อความที่สองฝั่งพูดเหมือนกัน (ปุ่ม Run, Stop…) ควรแปลให้ตรงกัน
